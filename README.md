# Robust Flood-Risk Prioritisation in India

This repository contains an audit of India's District Flood Severity Index (DFSI). The project verifies how strongly the released component datasets reproduce the published DFSI ranking, then tests whether district-level priority decisions remain stable under alternative component weights, fatality exponents, leave-one-component-out variants and analytical priority cutoffs.

The analysis preserves raw data unchanged, keeps incomplete records explicit,
and separates national ranking agreement from local priority-group stability.
Paper-ready tables, figures, claim audits and manuscript drafts are stored in
`paper/` and `outputs/`.
