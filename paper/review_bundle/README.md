# Paper Review Bundle

This bundle contains the manuscript scaffold, claim-audit material, paper-ready tables and paper-ready figures for review.

## Included Files

- `manuscript.md`: Manuscript scaffold with drafted methods and results prose.
- `results_claims_audit.csv`: Traceability table linking headline paper claims to source output files and source rows or filters.
- `figure_captions.md`: Captions for the main and supplementary figures.
- `table_captions.md`: Captions for the main paper tables and supplementary district-level tables.
- `table_1_reproduction_summary.csv`: Main paper table summarising DFSI reproduction sample size, correlations, differences and priority-group overlap.
- `table_2_component_and_weight_sensitivity.csv`: Main paper table summarising component contributions, leave-one-component-out sensitivity and fatality-exponent sensitivity.
- `table_3_monte_carlo_and_cutoff_summary.csv`: Main paper table summarising Monte Carlo weight uncertainty and priority-cutoff sensitivity.
- `paper_output_manifest.csv`: Manifest describing paper-ready outputs, source notebooks, source tables, manuscript sections and validation notes.
- `paper_figure_1_dfsi_reproduction.png`: Main Figure 1 showing DFSI reproduction scatterplots and top-group overlap.
- `paper_figure_2_component_influence.png`: Main Figure 2 showing component contribution and leave-one-component-out decision sensitivity.
- `paper_figure_3_monte_carlo_uncertainty.png`: Main Figure 3 showing moderate-scenario Monte Carlo priority uncertainty.
- `paper_figure_4_cutoff_sensitivity.png`: Main Figure 4 showing priority-cutoff sensitivity across fixed district counts.
- `supplementary_figure_1_reporting_completeness.png`: Supplementary Figure 1 showing historical reporting volume and completeness.
- `supplementary_figure_2_fatality_exponent.png`: Supplementary Figure 2 showing fatality-exponent sensitivity.
- `supplementary_figure_3_weight_scenarios.png`: Supplementary Figure 3 comparing narrow, moderate and wide Monte Carlo uncertainty scenarios.
