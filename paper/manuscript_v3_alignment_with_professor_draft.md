# V3 Alignment With Professor-Facing Draft

This note compares `paper/manuscript_main_v3.md` with the earlier professor-facing draft, `paper/manuscript_temporal_validation_draft.md`.

## Alignment Summary

V3 remains aligned with the professor-facing draft. It preserves the same research direction, the same working title, the same two validation components and the same narrow methodological claim.

## Working Title

Both drafts use the same working title:

**Do Complex Flood-Priority Rankings Add Value? Satellite and Temporal Validation of District Flood Prioritisation in India**

## Validation Components

Both drafts retain the same two validation components:

1. A main satellite-derived inundation comparison using the Global Flood Database to evaluate physical flood burden.
2. A secondary non-overlapping temporal test using earlier district flood history to rank later primary assignable recorded district fatalities.

## Main Findings Retained

V3 keeps the same main findings:

- The equal-weight physical-hazard index corresponded more strongly with satellite-derived inundation than the mixed DFSI.
- The fitted temporal fatality model showed predictive signal but did not robustly outperform simple past flood-event frequency.
- State-block uncertainty weakened claims of fitted-model superiority.
- Reporting completeness and fatality assignment limit temporal interpretation.
- The study supports construct separation rather than claiming that DFSI is invalid or that a new index is superior.

## Narrow Methodological Claim Retained

Both drafts support the same narrow claim:

Complex composite flood-priority rankings and fitted models should be validated against their specific decision target and compared with simple objective-specific indicators before added complexity is treated as useful.

## V3 Differences

The differences in V3 are wording and limitation clarifications, not a change in research direction:

- V3 replaces broad fatality-missingness wording with a specific fatality-assignment reason audit.
- V3 distinguishes missing fatality fields, unallocated multi-district fatalities, unmatched district records, state-only/non-district locations and confirmed reported zero fatalities.
- V3 states that the temporal outcome is primary assignable recorded district fatalities.
- V3 states that zero means no assignable recorded deaths, not confirmed absence of deaths.
- V3 adds the dataset source detail: Version 4 of the India Flood Inventory–Impacts dataset, Zenodo DOI `10.5281/zenodo.16994648`, accessed 29 July 2026.
- V3 confirms that the original DFSI district-allocation procedure could not be verified from the released documentation.

## Conclusion

V3 remains aligned with the professor-facing draft. The new material strengthens the limitation language around fatality assignment and source documentation while preserving the same central question and paper direction.
