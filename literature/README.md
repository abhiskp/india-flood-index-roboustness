# Literature Review Workspace

This folder contains the literature-review structure for the India flood-index robustness and predictive-ranking project.

- References must be verified against original publisher pages, DOI records, PubMed, DOAJ, Crossref/OpenAlex, institutional repositories or other authoritative databases.
- No citation should be added solely from model memory.
- PDFs may be stored in `included_papers/` only where legally downloaded.
- Papers excluded during screening may be documented in `excluded_papers/` where useful.
- The literature matrix, `literature_matrix.csv`, is the source of truth for manuscript citations.
- Quantitative analysis is frozen while literature screening is underway.
- Do not modify frozen notebooks, analytical tables, figures, raw data or the old manuscript during literature review.

Current screening status is tracked in `screening_progress.md`; actual searches are tracked in `search_log.md`; reusable query strings are in `search_queries.md`.
